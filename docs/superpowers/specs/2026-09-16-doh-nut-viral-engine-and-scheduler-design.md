# 🚀 Doh-Nut Viral & FYP Engine + Durable Scheduler Architecture Design

> **Engineering specification for implementing the Khairul Aming Proven Viral & FYP Certainty Engine, Platform Constraints Validator, and SQLite WAL Durable Delayed Job Scheduler for Hermes-WebApp and Doh-Nut Sovereign Operations.**

---

## 1. Executive Summary & Problem Context

### 1.1 The Problem
1. **Unpredictable Social Reach (The "Cold-Start Guessing" Dilemma)**: Current automated social media drafts generated by LLMs tend to be generic, corporate, and lack emotional hook, resulting in sub-par algorithmic engagement on TikTok and Instagram Reels.
2. **Missing Media & Platform Constraint Guards**: Social media platforms strictly reject or penalize content that violates their format rules (e.g., non-vertical 9:16 videos on TikTok, captions exceeding 280 characters on X, or missing `#Shorts` tags).
3. **Fragile In-Memory Scheduling**: Previous task scheduling relied on in-memory crons or ephemeral processes that lost pending posts if the host PC or FastAPI server restarted.

### 1.2 The Solution
Adopting proven patterns from **[Postiz](https://github.com/gitroomhq/postiz-app)** and empirical viral marketing frameworks from **Khairul Aming (KA)**:
- **Khairul Aming Proven Viral Playbook (`config/viral_playbook.json`)**: Pre-loaded bank of battle-tested 3-second hooks, sensory keyword triggers, relatable storytelling arcs, and debate-loop CTAs.
- **Automated Viral Score Linter (`backend/services/viral_engine.py`)**: Real-time evaluation scoring drafts from 0 to 100 with an enforced **85/100 threshold** for "FYP Certified" status.
- **Platform Constraints Validator (`backend/services/social_validator.py`)**: Enforces exact platform rules (character limits, 9:16 aspect ratios, duration caps).
- **SQLite WAL Durable Delayed Job Scheduler (`backend/services/durable_scheduler.py`)**: Zero-loss persistent task queue surviving system reboots, polled every 5 seconds via FastAPI lifespan asyncio worker.

## 3. Detailed Component Specifications

### 3.1 Khairul Aming Viral Playbook (`config/viral_playbook.json`)
A pre-loaded, evidence-backed knowledge bank of viral F&B hooks and structures:
- **3-Second Sensory Hooks**:
  - `QUESTION`: *"Ramai tanya kenapa donut kitorang tak pernah kempis lepas sejuk..."*
  - `SHOCK_DIET`: *"Jangan tengok video ni kalau korang tengah diet atau lapar..."*
  - `BTS_SECRET`: *"Rahsia doh gebu 48 jam yang bakeri lain takkan bagitahu korang..."*
  - `ASMR_CRUNCH`: *"Dengar bunyi kerak rangup ni bila disira gula panas..."*
- **Sensory Vocabulary Trigger Matrix**:
  - Positive triggers: `gebu`, `rangup berderap`, `leleh karamel`, `panas berasap`, `uli 48 jam`, `mentega asli`, `coklat pekat`, `tarik bertali`.
- **4-Phase Khairul Aming Script Structure**:
  1. `hook_3s`: Sensory/visual satisfaction gap + high-contrast text.
  2. `story_relatable`: Humble, authentic tone (*"Hari ni saya nak kongsi..."*).
  3. `climax_asmr`: Fast cut cadence (1.2s–1.8s) showing boiling oil, dough rising, glaze dripping.
  4. `organic_scarcity_cta`: Comment debate trigger (*"Korang team Kuih Burger donut atau team Matcha?"*) + batch limitation notice.

### 3.2 Viral Score Linter (`backend/services/viral_engine.py`)
- **Model**: `ViralScore`:
  - `hook_score` (0–25): Detected 3-second hook trigger.
  - `sensory_score` (0–20): Frequency and placement of high-arousal sensory words.
  - `pacing_score` (0–20): Sentence brevity and kinetic rhythm (words per sentence < 14).
  - `engagement_score` (0–20): Presence of interactive question/comment loop.
  - `scarcity_score` (0–15): Soft urgency / limited batch notice.
  - `total_score` (0–100): Weighted sum.
  - `is_fyp_ready` (bool): `total_score >= 85`.
  - `suggestions` (list[str]): Concrete replacement sentences if score < 85.

### 3.3 Platform Constraints Validator (`backend/services/social_validator.py`)
- **Validation Rules**:
  - **TikTok**: Max 2,200 chars, max 10 hashtags. Media must be vertical video (aspect ratio 9:16, max duration 10 mins). Requires human confirmation.
  - **Instagram**: Max 2,200 chars, max 30 hashtags. Reels (9:16) or Carousel (1:1 / 4:5, max 10 items).
  - **Threads**: Max 500 chars. Media freeform. Auto-splits into threads if exceeding 500 chars.
  - **X (Twitter)**: Max 280 chars. Media max 4 images or 140s video. Auto-trims text cleanly at punctuation boundary.
  - **Facebook**: Max 63,206 chars. Aspect ratio 16:9 or 1:1.
  - **YouTube Shorts**: Max 100 char title, 5,000 char description. Video duration must be strictly `< 60s` and aspect ratio `9:16`. Wajib `#Shorts`.

### 3.4 SQLite WAL Durable Scheduler (`backend/services/durable_scheduler.py`)
- **Schema (`scheduled_jobs`)**:
  ```sql
  CREATE TABLE IF NOT EXISTS scheduled_jobs (
      id TEXT PRIMARY KEY,
      campaign_id TEXT,
      project_slug TEXT NOT NULL,
      platform TEXT NOT NULL,
      action TEXT NOT NULL,
      payload TEXT NOT NULL,
      execute_at TIMESTAMP NOT NULL,
      status TEXT NOT NULL DEFAULT 'pending',
      attempts INTEGER NOT NULL DEFAULT 0,
      max_attempts INTEGER NOT NULL DEFAULT 3,
      last_error TEXT,
      receipt TEXT,
      created_at TIMESTAMP NOT NULL,
      updated_at TIMESTAMP NOT NULL
  );
  CREATE INDEX IF NOT EXISTS idx_scheduled_jobs_dispatch 
  ON scheduled_jobs(status, execute_at);
  ```
- **Execution Semantics**:
  - **At-least-once with idempotency**: Each job has a deterministic hash preventing duplicate runs.
  - **Crash resilience**: On FastAPI startup, all jobs marked `running` are investigated and reverted to `pending` (if `attempts < max_attempts`) or marked `interrupted`.
  - **Async Worker**: Runs on a 5-second `asyncio.sleep` loop without blocking FastAPI request threads.

## 5. Verification & Testing Strategy

- **`tests/test_viral_engine.py`**:
  - Verifies hook detection, sensory keyword scoring, and suggestion generation.
  - Asserts that poor generic corporate copy scores `< 60` and fails FYP threshold.
  - Asserts that KA playbook generated copy scores `>= 85`.
- **`tests/test_social_validator.py`**:
  - Verifies character limits on X (280) and Threads (500).
  - Verifies auto-trim behavior.
  - Verifies TikTok and YouTube Shorts 9:16 and duration limits.
- **`tests/test_durable_scheduler.py`**:
  - Verifies job scheduling in SQLite WAL.
  - Verifies worker execution when `execute_at <= now`.
  - Verifies crash recovery (interrupted job resumption).
  - Verifies max attempts backoff.
- **`tests/test_social_api.py`**:
  - Verifies REST endpoints for scoring, generating, scheduling, and listing jobs.
