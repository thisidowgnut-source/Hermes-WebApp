Headless Social Scheduler

Arsitektur GitOps tanpa server: GitHub Actions + queue.json + Python script. Tiada Docker, tiada PostgreSQL, tiada VPS — hanya file dalam repo.

Workspace: C: Users delta delta delta delta delta File: .github/workflows/post_scheduler.yml Status: Proposal (struktur asal utuh)
Perbandingan Arsitektur
SaaS / Monolith

Postiz / VPS / Docker

  • Perlu PostgreSQL + Redis + Temporal
  • Beban RAM: 2GB-4GB berterusan
  • Kos: VPS / kad kredit diperlukan
  • Maintenance: Docker compose, crash DB
  • Deployment: Cloud / self-host (kompleks)
Serverless / GitOps

GitHub Actions + queue.json

  • Tiada DB — queue.json dalam Git
  • Beban server: RM0 (runner Microsoft)
  • Kos: Percuma (2,000 minit/bulan)
  • Maintenance: Push commit = deploy
  • State: Git commit log, tiada crash

✅ Struktur Asal Utuh — Tiada Perubahan
